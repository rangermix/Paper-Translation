# NB 全站文案与语义映射

2026-09-09。实施依据：NB-R06；最终验收证据在 NB backlog 的 P10/P12。

| 入口 / 原表达 | 当前表达与行为 | 保留的约束 |
| --- | --- | --- |
| 上传后先进入强制预检 | 上传并开始处理；自动解析、恢复、检查并生成阅读结果 | 外发必须绑定当次来源、服务和授权 |
| 来源全文确认 | 不再要求勾选全文校对；可选查看原文与调整解析 | 手动修改来源仍须提供真实 PDF 证据 |
| 结构预检 / 来源覆盖 | 解析结果 / 提取内容 | 原始 PDF、来源修订和定位证据保留 |
| 校对工作台 | 译文编辑；可直接封存、发布和导出 | 未保存修改、CAS 版本冲突继续保护 |
| 必须处理 / 阻断问题 | 重要提示；不影响阅读、发布或导出 | 非法 AST、路径、被篡改的资源仍不可渲染 |
| 风险审批 / 强制人工发布 | 一般提示默认折叠；新工作流默认自动发布 | 用户明确选择手动发布时间时保留该选择 |
| 缺失译文 | 标明此段尚无译文，保留原文 / 原图 | 不把原文冒充译文，不伪造完整性 |
| QA 过期 / 检查失败 | 报告待更新 / 检查未完成，可继续阅读和发布 | 封存时自动刷新；失败如实保留 |
| ready → 待发布 | 已就绪 | 与已发布、已封存区分 |
| 已验证 N 段 | 已完成 N 段 | 段落、单元、请求数分别统计 |
| 当前模型代填旧任务 | 实际模型 / 尚未记录实际模型 / 历史记录未保存 / 无需模型 | 不从当前设置猜测历史执行身份 |
| 任务完成时间空白 | 尚未结束 / 历史记录未保存 | 不生成虚假起止时间 |
| 任意错误统一版本变化 | 按错误码提供下一步，原始错误放技术详情 | 外发结果未知明确提示可能计费，不自动重试 |
| DOI 查询失败后空标题 | 保留原始文件名；无 DOI、待查询、失败、歧义分别显示 | 用户自定义题名不被覆盖 |
| 语言代码或统一中文名称 | 内置选项使用各语言本地名称；允许其他规范 locale | 脚本/地区代码及 API 绑定保留 |
| 原始英文隐私默认说明 | 中文说明授权文本范围与服务端存储边界 | 自定义服务政策原文保留 |
| 文档当前任务被索引任务覆盖 | 优先显示仍需处理的解析、翻译和发布任务 | 其他任务仍可在完整历史中查询 |

审查范围：上传、文档库、详情、解析结果、阅读、任务中心、译文编辑、设置、错误提示、历史和导出。内部 locale、错误码、模型 ID、API 协议和不可变版本标识仍可在技术详情中核对；旧 reader-v1 CSS 未改。
