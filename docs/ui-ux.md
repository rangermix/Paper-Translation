## 保存与离开

译文在当前编辑页集中保留输入；普通原文不会作为已存在的译文回填。需要时可显式“以原文开始编辑”。连续编辑仍保留已有格式、链接、交叉引用与受保护元素，模型不参与手工编辑。

应用内导航提供继续编辑、放弃修改、保存后离开。多段保存串行采用新 ETag；部分成功只清除已成功项，冲突与失败保留其余输入。刷新版本保留本地比较与人工采用新基准的步骤。刷新/关闭标签页使用浏览器提供的离开提示；未添加浏览器崩溃恢复承诺或译文持久化副本。

离开确认期间继续后退、前进或修改地址时，处理确认结果后也保持地址与当前页面一致；取消保留编辑输入。目录标题和标签以打开编辑时的版本为保存基准，后台刷新不会替换该基准。发现其他页面更新后，先展示最新内容供比较；采用最新内容或明确保留自己的输入后，仍需再次保存。

设置的每组表单保持挂载。保存后离开时，共享偏好更新串行取得新 ETag；一组失败不会抹掉其他输入。其他接口的未保存草稿不会被自动保存或启用。刷新服务设置保留非密钥输入供比较，未保存密钥按现有规则清空并提前说明。

阅读偏好、目录信息和原文校对在提交等待期间锁定对应输入，避免成功响应清除后来输入的内容。阅读、解析和资源设置再次修改后清除旧的保存成功提示，已有错误与冲突提示保留。

原文校对仍分为创建修正草稿、明确确认新来源两步。关闭工作区只处理其自身输入，不能清除父级译文修改；离开整页则逐层处理。它不提供会自动确认新来源的“保存后离开”。所有源文修正继续绑定 PDF 证据。

解析提示按页码从小到大排列，同页按类型稳定分组，页码未知的提示最后显示；组内原记录和证据顺序不变。版本历史读取失败时显示错误与重试入口，不同时宣称没有阅读版本。

## 信息层级与术语

管理界面支持简体中文（`zh-Hans`）、繁體中文（`zh-Hant`）和 English（`en`）。全局导航底部的“界面语言”即时切换；手机端从导航菜单进入。首次按浏览器语言顺序选择，中文保留脚本/地区区别，未支持的语言回退到 English。手动选择只保存在当前浏览器的 `paper-translation.ui-locale.v1`，同源标签页同步；浏览器禁止存储时仍能切换本页。

界面语言与默认翻译语言独立。切换不调用设置写入接口，不重新挂载表单，不修改未保存输入、论文正文、用户标题、任务配置或历史阅读版。应用文案、无障碍标签、状态、语言搜索说明与日期格式跟随界面语言；服务端原始诊断、日志、模型名称及源文证据保持原样。

翻译资源位于 `src/apps/web/src/locales/`，以简体中文源文案为键，每条包含 English 和繁體中文；`i18n.ts` 负责回退和参数插值。组件显式翻译应用文案，不遍历 DOM 或处理论文内容。新增文案须同时补全两种翻译，含动态值的句子使用命名参数。单元测试校验资源覆盖与参数一致性，`tests/browser/i18n.spec.ts` 验证语言选择、存储不可用、跨标签页同步、未保存输入和手机导航。

常用层显示用户作决策所需的文档标题、语言、真实状态、服务地址、模型、费用和内容。来源哈希、配置修订、模板兼容 ID、协议和鉴权方式放入可展开详情，信息仍可访问。外发确认附近的真实服务地址与模型保持可见。

“保存”只表示服务端成功；“保存为新版本”产生封存快照；“生成预览”不会切换当前阅读版；“生成下载文件”完成后才提供下载。任务链接根据同一个选中任务的 `current_job_status` 显示进度或最近记录，缺失状态时使用中性表述。

术语表保存独立修订。尚未添加的词条和整表未保存状态分别保护；影响预览仅查询已保存基准，不伪装为未保存修改的结果。指定文档的版本始终预览其已保存关联范围。并发创建各自保留，不虚构服务端尚未提供的术语 CAS 契约。

翻译记忆空页明确指向编辑器：保存译文，在“人工核对（可选）”中确认本段已核对，再显式另存。没有自动核对或自动制造人工记忆。

## 阅读与模型选择

`reader-v14` 从已封存译文取章节标题，与原文章节并列；无译文时只用原文，不调用模型。搜索结果仍绑定原命中阅读版本与段落，返回链接只接受同实例搜索路由。直接阅读退回文档；单文件和 ZIP 导出移除实例导航，在无网络、无 JavaScript 情况下仍可阅读。

新发布/草稿导出使用新模板，既有模板及资源不变。已有文档可明确生成新样式预览，切换仍需要不可变资源校验与 CAS；不批量重建或改写历史。

语言选择保留原生控件与所有规范 locale，提供名称/代码搜索、键盘选择和最多六个最近使用项。脚本、地区与历史自定义标签不合并；浏览器存储不可用时仍可选择。最近使用仅保存语言代码，不保存服务配置或密钥。

模型目录显示真实名称、来源 ID、准备与停用状态。资源参考是估算；未经测量的速度、质量和环境兼容性不会因名称含 Pro/Flash 等字样被推断。选择、保存与下载/测试是独立操作，已有任务配置快照不变。

任务中的模型名称仅从执行记录的本地模型 ID 与兼容修订匹配锁定目录，原 ID 保留在详情。未知模型、API 模型和修订冲突不会按当前设置猜测名称；模型筛选同时支持记录中的 ID 和已识别名称，在分页前筛选，并保持主任务与内部步骤的既有分组边界。

上传及翻译确认中的本地模型名称按本次配置的精确模型 ID 匹配目录，原 ID 放入连接技术详情。名称只用于公开响应的展示，不进入配置 hash、外发授权或任务快照；未知模型和 API 模型继续显示原 ID，真实服务地址始终可见。

## 验证边界

S01–S12 对应文库、上传、任务、文档管理、原文校对、译文编辑、版本导出、术语、记忆、设置、搜索、阅读器与移动导航。浏览器替身覆盖这些页面的桌面/手机状态、保存冲突和故障；真实持久化与不可变发布在独立 PostgreSQL 测试实例验证。

视觉检查测量文字与控件边界对比度、焦点、命中尺寸、窄屏和 200% 文本放大/等效 CSS 视口重排，并记录行内链接等适用例外。它不等于完整 WCAG 认证、真实屏幕阅读器评估、操作系统缩放或实体手机触控验收。模型推理质量、真实付费服务、生产 PDF 修改不因这些检查自动获得验证。

本地部署只更新经过验证的应用服务，核对 Compose 配置、镜像、网络、端口与持久卷；健康检查使用 `/health/ready`。功能写入验证留在隔离实例，生产巡检采用只读路径。运行结果必须附源码/镜像标记，不能由本指南推定任一部署已更新。
