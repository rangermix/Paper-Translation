# M2 产品 Spec · 个人校对、多语言和版本管理

**2026-09-08 用户补充：质量问题与段落定位。** 校对工作台将阻断与风险提示分组，并提供全部/仅阻断/仅风险筛选及对应段落跳转。阻断段落明确标为必须处理，不能显示可选核对；人工确认不能代替修正和重验。段落可独立折叠，非阻断段落默认折叠，跳转自动展开，折叠和筛选必须保留未保存文字与修改理由。数字检查仅作机械等价比较，不改写原文或已保存译文：统一千分位、PDF提取的小数间隔、数位宽度和明确的中英文数量单位（如 11 billion = 110 亿、3 billion = 30 亿）；仍检查精确数值、正负号、百分号和出现次数，并展示差异证据。规则版本改变使旧 QA 过期，重验后才可封存。

**2026-09-07 用户补充：取消译文强制人工核对/确认。** 段落确认、语义和术语问题核对均为可选；未确认或未处置的高风险提示不阻止封存、手动发布、自动发布或导出，提示及实际核对状态仍保留。缺段、数字/保护原子不一致、资源损坏等硬完整性问题和过期 QA 仍阻断。修改后只需重跑本地质量检查，不要求再次人工确认。此补充覆盖下文旧的强制核对表述；外发授权、未知请求风险处理及来源修正证据规则不变。

**版本3.0 · 个人PDF版 · 待实现**

## 1. 产品目标与前提

将长期阅读和修订工作闭环：PDF来源定位、术语、局部候选、人工核对、多目标语言、回滚、检索与零模型模板重建。

**进入条件：** M0/M1全部退出证据有效；使用带未完成任务、旧artifact和费用预留的M1数据库快照测试升级；没有新增多人协作范围。

本阶段只有一个使用者，不引入用户实体。规格依赖[产品基线](../00-product-baseline.md)、[共享数据契约](../shared/architecture-data.md)、[工作流和质量](../shared/workflow-quality-security.md)、[API](../shared/api-contract.md)、[Compose契约](../deployment/compose-contract.md)。

## 2. 核心流程与明确排除

打开已发表版 → 建草稿 → 对照PDF → 选择部分段落重译 → 比较候选 → 接受并确认 → 重验封存 → 新发布版；可新增语言、重建模板或回滚历史。

**排除范围：** 实时协作、账号级同步、角色审批、更多文件格式、RAG问答、图中文字重绘和未经认证语言质量保证不在范围。

## 3. 页面及状态规格

| 页面 | 必需信息与操作 | 边界 |
|---|---|---|
| PDF来源工作台 | 页码bbox、跨页高亮、机械清理与源码修订 | 不支持网页DOM/TXT locator；legacy不伪造 |
| 译文编辑器 | 逐段版本、保存/人工确认、QA问题、候选 | 候选异步返回不得覆盖当前人工修改 |
| 术语/记忆 | 个人全库与文档覆盖、词项修订、影响预览 | 没有组织范围或权限字段 |
| 版本与语言 | 每locale独立edition、差异、回滚、固定导出 | 版本不可变，模板升级不调用模型 |
| 全文搜索 | CJK字面子串、当前已发布片段、阅读位置 | 无ACL过滤；仍检查当前generation和删除状态 |

输入错误留在当前页并保留有效选择；耗时操作返回job而不是锁住界面。操作完成显示真实已完成范围，失败给对应资源/错误码；不以人工按“继续演示”的结果作为正式成功。

## 4. 编号需求与验收场景

以下每个MUST是退出门的一部分；AT均为待执行产品测试，不是本包自检结果。

### M2-R01 · PDF来源对照工作台

**MUST：** 工作台显示保存的原PDF页图、当前块、机械清理记录、译文与问题；bbox统一top-left-points，并支持裁剪框、旋转和跨页多定位。只有PDF定位组件，没有DOM/TXT定位面板。legacy无精确来源时诚实降级。

**M2-AT01A** （自动化＋人工/环境验证，planned）

Given 跨两页段落，When 点击来源定位，Then 两个真实原页片段正确高亮且显示页码／坐标转换。

**M2-AT01B** （自动化＋人工/环境验证，planned）

Given legacy 文章无逐块来源，Then 显示“无精确定位”与原件入口，不合成虚构 bbox。

### M2-R02 · 可编辑草稿与不可变修订

**MUST：** TranslationDraft 可编辑；每次更改追加 SegmentVersion 并增加 draft generation。封存后产生不可变 TranslationRevision 快照，历史结果保留。仅目标文本／AST可修改，源文修改另走来源修订。

**M2-AT02A** （自动化，planned）

Given 已发布版开始修改一个段落，When 保存并封存，Then 新译文修订有parent/base和操作来源/时间/原因，旧修订哈希不变。

**M2-AT02B** （自动化，planned）

Given 使用旧ETag覆盖、重复提交或访问不属本草稿的block，Then 412/幂等返回/404，不覆盖其他更改。

### M2-R03 · 个人术语表修订

**MUST：** 按源/目标语言管理精确词项、推荐译法、允许变体、禁用译法、原样保留和注释。修改产生不可变GlossaryRevision；文档专用项覆盖个人全库项，同级冲突在派发前解决。没有组织/成员或术语ACL。

**M2-AT03A** （自动化，planned）

Given 全库术语和某文档覆盖项不同，When 确认翻译，Then 固定有效合并快照及优先级，并预览受影响块。

**M2-AT03B** （自动化，planned）

Given 同级词项互斥强制译法，Then GLOSSARY_CONFLICT；不随机选取或悄悄覆盖。

### M2-R04 · 术语作用范围与影响预览

**MUST：** 新增／修改术语只影响显式新任务，旧发布版不变。匹配规则版本化，区分大小写、单词边界与CJK子串，不执行任意用户正则。预览受影响块后可建局部重译候选。

**M2-AT04A** （自动化，planned）

Given 修改3个术语但仅2块包含匹配词，When 查看影响并确认，Then 只为这2块建立候选，快照可追踪。

**M2-AT04B** （自动化，planned）

Given 人工已锁定块含新术语，Then 提示潜在冲突但不自动覆盖，旧审校状态仍对应旧术语版本。

### M2-R05 · 局部重译不伤及已审校内容

**MUST：** 用户按块／章节/问题选择候选重译；仅选定单元发给模型，但带固定局部上下文。候选结果与当前译文并排，明确接受后才更新草稿。已人工确认内容默认锁定，不被批量结果替换。

**M2-AT05A** （自动化，planned）

Given 100段中2段请求重译、其余98段已审校，When 候选完成，Then 98段内容与审校记录字节不变，只存在2段待选择候选。

**M2-AT05B** （自动化，planned）

Given 批量接受试图触及未明确选中的锁定块，Then 409并列出块，不能默认全覆盖。

### M2-R06 · 审校状态可信

**MUST：** segment区分 not_reviewed、machine_checked、human_reviewed，并绑定源 hash、目标版本和术语/QA基线；人改不自动等于人已确认。任何目标修改使该段确认失效；审校动作不可伪装为机器输出。

**M2-AT06A** （自动化，planned）

Given 人工确认后再次修改一个字符，When 保存，Then 仅该段审校状态失效，保留此前确认历史。

**M2-AT06B** （自动化，planned）

Given Provider返回 human_reviewed 字段或自评分100，Then 忽略／拒绝该字段，不增加人工确认数。

### M2-R07 · 质量报告和问题处置闭环

**MUST：** 问题有 severity、rule/version、block/unit、证据和当前指纹。硬结构阻断不能忽略；语义风险可通过具体源对照确认解决；允许的警告可带原因接受并进入出版质量说明。检查结果过期需重算。

**M2-AT07A** （自动化，planned）

Given 否定／比较风险经人工对照确认且内容不变，When 标记已核对，Then 留下证据与操作来源(manual_ui/system)，允许按政策发布。

**M2-AT07B** （自动化，planned）

Given 缺块／资产hash错误尝试“忽略”，Then 操作拒绝；旧 QA 报告不得批准新草稿。

### M2-R08 · 辅助语义评审有边界

**MUST：** 可配置独立评审调用检查遗漏、否定、数字关系与术语。它只生成有定位的issue，不直接编辑，也不把评分宣称为准确率；按同样预算、授权、重试和隐私流程执行。默认不开启额外付费评审。

**M2-AT08A** （自动化＋人工/环境验证，planned）

Given 用户启用受预算约束的评审，When 返回风险，Then 每条issue附源/译片段和规则；用户可复核。

**M2-AT08B** （自动化＋人工/环境验证，planned）

Given 评审模型不可用或预算不足，Then 该评审状态明确未完成；不得伪称审查通过，也不自动换供应商。

### M2-R09 · 多目标语言 edition

**MUST：** 同一 Document 和 SourceRevision 可拥有多个 target locale，唯一键(document_id,target_language)。新增语言复用源件/解析/资产，但创建独立译文与当前 artifact 指针；所有语言均可直接选择，实际质量取决于所选模型。

**M2-AT09A** （自动化，planned）

Given 中文版已发布，When 从同一英文源新增日语版，Then 解析器调用数为零、中文 artifact/current pointer不变。

**M2-AT09B** （自动化，planned）

Given 对已存在locale再次创建，Then 返回既有edition或显式新revision流程，不生成重复edition或覆盖另一语言。

### M2-R10 · 语言能力与混合文本声明

**MUST：** locale使用规范化标签，保留脚本地区差异；来源语言可按块覆盖。所有语言与组合均开放，不使用实验模式、额外语言确认或语言专属发布限制；选项及语言标签使用各自语言的名称。来源未确定时仍需人工选择；语言开放不代表任意模型的质量或RTL布局已获认证。

**M2-AT10A** （自动化，planned）

Given zh-Hans与zh-Hant两个目标，When 建版与切换，Then 独立指针、标签与缓存，不被统一折叠为zh。

**M2-AT10B** （自动化，planned）

Given 任意规范语言标签，Then 无需额外语言确认即可建版和翻译，显示语言自身名称；低置信来源仍需人工选择，不自动当en处理。

### M2-R11 · 来源修正与新来源版本

**MUST：** 允许在来源工作台修正解析顺序、漏页映射、段落拆并和机械文本误提取，必须核对本地原件并保存理由。产生新的 SourceRevision，原件不变时复用资产，新文件时新资产；不能改写原作者内容为“更通顺”。

**M2-AT11A** （自动化，planned）

Given 双栏顺序误判，When 修复并确认，Then 产生新source revision与差异记录，旧版原文和发布页保持。

**M2-AT11B** （自动化，planned）

Given 用户试图从译文编辑端改变源文或无证据添加一段作者未写的内容，Then 阻止并要求走显式非忠实注释，而非篡改原文。

### M2-R12 · 跨来源修订映射与失效

**MUST：** 新旧源块映射分类 exact/moved/changed/split/merged/unmatched；稳定ID只保证版本内。只有内容、保护原子及上下文指纹完全相同才可复用，changed/split/merged须重译或人工搬迁；上下文变化也须失效相关缓存/审校。

**M2-AT12A** （自动化，planned）

Given 新文件只在前面插入一段，When 对比映射，Then 未变块通过内容和上下文校验识别，不因顺序号碰巧相同而错配。

**M2-AT12B** （自动化，planned）

Given 文本相同但章节语境或数字原子变化，Then 不继承旧 human_reviewed 和精确缓存，不静默迁移。

### M2-R13 · 修订差异与审计

**MUST：** 展示源/译版本摘要及按块差异，包含新增、删除、移动、修改、重译来源、术语/模型/提示变化和人工接受记录。审计可追踪但不会在普通列表泄露全文。

**M2-AT13A** （自动化，planned）

Given 一次源更改与一次目标局部更改，When 对比两版本，Then 明确区分源变化与译变化，能定位到具体块和决策。

**M2-AT13B** （自动化，planned）

Given 自动候选未被接受，Then 不出现在已发布版本内容中，不能把候选生成时间当出版时间。

### M2-R14 · 并发校对与候选安全合并

**MUST：** M2仍非实时协同编辑器；多个标签页通过ETag与逐块版本检测防止覆盖。接受候选须匹配base target version、source hash及glossary。冲突时保留双方结果，用户明确选用或合并。

**M2-AT14A** （自动化，planned）

Given 候选运行时用户改了同一段，When 候选返回后点接受，Then 提示差异冲突且当前修改不丢失。

**M2-AT14B** （自动化，planned）

Given 两个接受请求同时使用旧base，Then 至多一个成功，另一个412；不最后写入胜出。

### M2-R15 · 发布审批、历史与回滚

**MUST：** 每个语言版独立发布；发布封存特定草稿、QA、template，再以单调generation CAS切换。回滚只切换到同文档同locale且完整可读的既有artifact，新增publication event，不改写历史。

**M2-AT15A** （自动化，planned）

Given A→B发布后回滚A，When 读取当前，Then 返回A，generation继续递增，B仍可由历史进入。

**M2-AT15B** （自动化，planned）

Given 跨文档/跨语言artifact、缺失资产、已删除文档或ABA旧generation回滚，Then 拒绝且当前不变。

### M2-R16 · 仅换模板的零模型重建

**MUST：** 模板注册具有ID、版本、CSS/JS/renderer hash和安全审核。为现有冻结源/译快照生成新artifact，预览确认后切换；可批量排队，保持失败文档当前版本不变。reader-v1永不原地修改。

**M2-AT16A** （自动化，planned）

Given 20篇已发表文档和新批准模板，When 执行仅重排构建，Then Provider调用与翻译缓存写入均为0，旧制品字节不变。

**M2-AT16B** （自动化，planned）

Given 新模板不支持某种结构或资源构建失败，Then 仅该文档报错，不全局切到半成品，不回退让模型写HTML。

### M2-R17 · 个人翻译记忆候选

**MUST：** 精确机器缓存与人工翻译记忆分开。显式保存已核对的源/目标/上下文/来源引用；近似命中仅是候选，显示差异，接受前不写当前译文。默认随来源文档永久删除；用户可在删除前明确另存为独立个人词句条目，不存在跨用户隔离。

**M2-AT17A** （自动化，planned）

Given 两个相似但不同句子，When 匹配，Then 显示差异与原件来源，未接受不能成为正式译文。

**M2-AT17B** （自动化，planned）

Given 来源已永久删除且未明确独立保存，Then 记忆及索引不可再返回，后台回收不误删仍被使用资产。

### M2-R18 · 个人正文检索与阅读位置

**MUST：** 检索当前已发布源/译文，承诺字面子串匹配、保留CJK语义，结果链接artifact+block。阅读进度为实例级(document,locale,artifact)记录，多浏览器共享，无账户ID。索引异步更新前必须复核当前generation及删除状态。

**M2-AT18A** （自动化，planned）

Given 连续中文词组或英文原文查询，When 检索，Then 返回当前已发布匹配片段及固定版本锚点。

**M2-AT18B** （自动化，planned）

Given 发布/撤销/删除与索引更新并发，Then 不返回旧当前/已删除片段；无效书签提示迁移，不错误跳段。

### M2-R19 · 精确导出与 Compose 备份

**MUST：** 可选具体artifact导出单文件HTML或目录ZIP，原PDF仅显式包含。完整备份覆盖数据库/IR/源件/版本/账本，通过Compose内CLI验证和恢复，无Web上传ZIP/JSON入口，不包含Provider密钥和私有诊断日志。恢复不是新增文档方式。

**M2-AT19A** （自动化，planned）

Given 选择旧版本与include_source，When 导出，Then 输出旧版完整内容、资源hash与原PDF，离线无需网络。

**M2-AT19B** （自动化，planned）

Given 下载前文档已永久删除或备份内容hash不符，Then 拒绝提供/恢复；已下载的离线副本不可撤回。

### M2-R20 · 可靠性、删除和迁移回归

**MUST：** 扩展缓存、记忆、索引、候选和旧版本后，删除、备份、恢复和数据库迁移仍覆盖所有对象。迁移采用先扩展后切换，先备份并验证回滚方案；读取旧sealed artifact不需强制升级。

**M2-AT20A** （自动化＋人工/环境验证，planned）

Given M1数据含未完成任务、旧制品和预算预留，When 升级M2并恢复演练，Then 数据一致、unknown不重复派发、旧文章仍可读。

**M2-AT20B** （自动化＋人工/环境验证，planned）

Given 删除同时有重建／候选写入／检索更新，Then tombstone和版本检查阻止复活，GC只删无引用对象。

### M2-R21 · 完整编辑出版验收

**MUST：** 端到端必须包含一个真实来源修正、一次锁定段落局部重译、两种目标语言、语义核对、冲突、模板重建、回滚与离线导出。所有M0/M1门禁继续有效，不以功能增加为理由放宽原文忠实性。

**M2-AT21A** （自动化＋人工/环境验证，planned）

Given 完整产品验收脚本，When 依序运行，Then 每步有版本/预算/审校证据且全部计划测试通过。
