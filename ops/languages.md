# 语言与配置确认

2026-09-07 起，所有语言和来源/目标组合均可直接使用，取消实验语言、逐次语言确认、实验标记和语言专属手动发布限制。自动发布仍检查来源版本、授权、预算（启用时）和任务状态；2026-09-09 起内容质量提示统一非阻断。

上传、预检、建版、设置、术语、任务及版本标签使用语言自身名称，例如 English、日本語、Deutsch、français、简体中文、繁體中文。选择器提供常见语言；“其他语言…”可填写标准语言标签，如 ast、pt-BR。浏览器缺少某种语言的本地名称时保留该代码，不误用另一语言的名称。

API 按语言标签规范化大小写，保留脚本与地区区别；zh-Hans、zh-Hant、pt、pt-BR不合并。标签最长32字符，与既有数据库列一致。und/auto 等未确定来源仍须对照原件后明确选择，禁止路径字符或无效标签。

`GET /api/v1/capabilities` 和 `/settings/provider` 返回 `language_policy: all`，不再公布受限语言矩阵。旧公开 profile 的 enabled_pairs 保留为历史配置数据，不参与语言可用性判断，也不为开放语言改写原配置/hash或凭据。

建立语言版、确认来源、已有来源翻译、候选与语义评审仍要求服务端给出的完整 `profile_hash`。付费入口另需配置版本和独立外发确认；成本控制开启时须有金额预算。模型、价格或目的地发生变化，旧确认仍返回 PROFILE_STALE。

不再提交 experimental_confirmed。新任务/草稿/发布不产生语言实验元数据；历史列和不可变出版文件保留，旧文件不会被原地改写。语言开放不构成模型质量认证，也不授权 agent 使用真实 API key 或执行真实模型验收。
